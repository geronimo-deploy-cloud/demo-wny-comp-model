# comp_model

ML model serving API generated by Geronimo.

## Quick Start

```bash
# Install dependencies
uv sync

# Run the API locally
uv run uvicorn comp_model.api.main:app --reload

# Run tests
uv run pytest
```

## Project Structure

```
comp_model/
├── geronimo.yaml          # Deployment configuration
├── pyproject.toml         # Python project config
├── Dockerfile             # Container definition
├── azure-pipelines.yaml   # CI/CD pipeline
├── infrastructure/        # Terraform files
├── src/
│   └── comp_model/
│       ├── sdk/           # Geronimo SDK definitions
│       │   ├── endpoint.py   # Request handling
│       │   ├── model.py      # Model definition
│       │   ├── features.py   # Feature engineering
│       │   └── data_sources.py
│       ├── app.py         # FastAPI application
│       ├── train.py       # Model training script
│       └── monitoring/    # Metrics & alerts
├── models/                # Model artifacts
└── tests/
```

## Deployment

```bash
# Generate all deployment artifacts
geronimo generate all

# Deploy infrastructure
cd infrastructure && terraform apply
```
