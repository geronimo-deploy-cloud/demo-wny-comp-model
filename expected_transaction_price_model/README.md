# expected_transaction_price_model

ML model serving API generated by Geronimo.

## Quick Start

```bash
# Install dependencies
uv sync

# Run the API locally
uv run uvicorn expected_transaction_price.app:app --reload

# Run tests
uv run pytest
```

## Project Structure

```

├── pyproject.toml
├── src/
```
