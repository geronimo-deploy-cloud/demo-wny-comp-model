# geographic-feature-store

ML batch pipeline generated by Geronimo.

## Quick Start

```bash
# Install dependencies
uv sync

# Train the model
uv run python -m geographic_feature_store.train

# Run the batch pipeline locally
uv run python -m geographic_feature_store.flow run

# Run tests
uv run pytest
```

## Project Structure

```
geographic-feature-store/
├── geronimo.yaml          # Deployment configuration
├── pyproject.toml         # Python project config
├── src/
│   └── geographic_feature_store/
│       ├── sdk/           # Geronimo SDK definitions
│       │   ├── pipeline.py   # BatchPipeline definition
│       │   ├── model.py      # Model definition
│       │   ├── features.py   # Feature engineering
│       │   └── data_sources.py
│       ├── flow.py        # Metaflow orchestration
│       ├── train.py       # Model training script
│       └── monitoring/    # Drift detection & alerts
├── batch/                 # Batch job data (input/output)
├── models/                # Model artifacts
└── tests/
```

## Deployment

```bash
# Generate all deployment artifacts
geronimo generate all

# Deploy batch pipeline to Step Functions
uv run python -m geographic_feature_store.flow step-functions create
```
